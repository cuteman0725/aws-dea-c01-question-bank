Q1Glue Job 連 S3 出現 S3 VPC gateway endpoint 問題▶
Q1. A data engineer is configuring an AWS Glue job to read data from an Amazon S3 bucket. The data engineer has set up the necessary AWS Glue connection details and an associated IAM role. However, when the data engineer attempts to run the AWS Glue job, the data engineer receives an error message that indicates that there are problems with the Amazon S3 VPC gateway endpoint. The data engineer must resolve the error and connect the AWS Glue job to the S3 bucket. Which solution will meet this requirement?
Q1. 一名資料工程師正在設定AWSGlue工作以從AmazonS3儲存桶讀取資料。該 資料工程師已設定必要的AWSGlue連線詳細資訊及關聯的IAM角色。然而， 當該資料工程師嘗試執行AWSGlue工作時，收到一則錯誤訊息，指出 AmazonS3VPC閘道端點存在問題。該資料工程師必須解決此錯誤並將AWS Glue工作連線至S3儲存桶。 哪項解決方案符合此需求？
A)
Update the AWS Glue security group to allow inbound traffic from the Amazon S3 VPC gateway endpoint.
更新AWSGlue安全群組，允許來自AmazonS3VPC閘道端點的入站流量。
S3 gateway endpoint 不靠 SG inbound 放行；核心是 route table。
B)
Configure an S3 bucket policy to explicitly grant the AWS Glue job permissions to access the S3 bucket.
設定S3儲存貯桶原則，以明確授予AWSGlue工作存取S3儲存貯桶的權限。
可能也是權限層考量，但題目錯誤明確指向 S3 VPC gateway endpoint 連線問題。
C)
Review the AWS Glue job code to ensure that the AWS Glue connection details include a fully qualified domain name.
檢視AWSGlue工作程式碼，確保AWSGlue連線詳細資訊包含完整網域名稱。
Glue 連 S3 不靠手動填 fully qualified domain name 解決 endpoint route 問題。
D)
Verify that the VPC's route table includes inbound and outbound routes for the Amazon S3 VPC gateway endpoint.
驗證VPC的路由表是否包含針對AmazonS3VPC閘道端點的輸入與輸出路由。
✔ Correct Answer: D
Network（S3 VPC Gateway Endpoint / Route Table）
AWS Glue Amazon S3 VPC gateway endpoint route table private connectivity

一句考點

Glue job 在 VPC 內讀 S3，如果錯誤指向 S3 VPC gateway endpoint，優先檢查相關 subnet 的 route table 是否有 S3 prefix list / gateway endpoint route。

為什麼

  • S3 Gateway Endpoint 是透過 VPC route table 生效，不是靠 security group inbound rule。
  • Glue job 若在 VPC subnet 中執行，必須能透過該 subnet 關聯的 route table 走到 S3 endpoint。
  • 若 route table 沒有指向 S3 prefix list 的 gateway endpoint route，Glue 就可能無法私下連到 S3 bucket。

超短流程圖

Glue job subnet → route table has S3 prefix-list route → S3 gateway endpoint → S3 bucket
